# Mobility Parking Scheme Web Application

This project is a web-based application designed to allow residents to apply for a Mobility Parking Permit online. The system simplifies the application process by enabling users to register, log in, and submit required information through an easy-to-use interface.

Features
- User registration and login system
- Online mobility parking permit application
- Multi-section application form
- Clear navigation and user-friendly interface
- Form validation for accurate data entry

Technologies Used
- HTML
- CSS
- JavaScript

Purpose
This project was developed as part of a Systems Analysis & Design academic project to demonstrate how a digital solution can streamline mobility parking permit applications for residents and authorities.

Learning Outcomes
Through this project, I developed skills in:
- Building structured web interfaces
- Implementing form validation
- Creating user-friendly navigation flows
- Organizing front-end project architecture
- Applying usability principles to real-world scenarios

Future Improvements
- Backend database integration
- User dashboard and application tracking
- Email notifications for application updates
- Accessibility enhancements
